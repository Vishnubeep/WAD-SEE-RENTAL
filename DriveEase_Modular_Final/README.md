# DriveEase Business Rental Management System

A modular HTML, CSS and JavaScript prototype for a vehicle rental company's internal operations.

## Folder structure

- `html/` — one page per business module.
- `css/` — base, layout and page-specific styles.
- `js/` — data, storage, helpers, shared modals, and page-specific logic.
- `assets/` — reserved for vehicle images or other static assets.

## Pages

- Dashboard
- Fleet
- Customers
- Reservations
- Returns
- Maintenance
- Payments

## Running the prototype

Open `html/dashboard.html` in a browser. No build tool, framework or npm installation is required.

The prototype stores demo changes in browser `localStorage`.
